## Integration contract
`python tests/native-app/runner.py --apk ABS --receipt ABS --result ABS [--journeys ABS]`

Receipt: source_sha, apk_sha256, signer_sha256, assets_sha256 mapping the complete intended assets/public file set plus assets/capacitor.config.json. Producer must derive expectations from reviewed build output and the independently generated ephemeral key, not blindly bless any APK. Runner compares actual checkout identity, full APK hash, sole signer, package, asset set/bytes, config origin/appId and absence of INTERNET/Google service resource values. It verifies installed base.apk bytes before launch. Build preparation must independently inspect merged permissions, prohibit credentials/production endpoints, prove real Android entry and exclude live snapshot generators. Hash agreement alone is not proof of safe artifact construction.

Runner uses a fresh owned AVD, refuses preexisting adb devices, pins emulator port and AOSP35 x86_64, bounds subprocess operations and boot, and cleans the emulator/owned AVD. It starts exact acceptance package/real MainActivity; package PID and its WebView socket scope the localhost target. Explicit proxy-free, no-redirect discovery rejects foreign or ambiguous pages. Response bytes and socket operations are bounded; the outer CI job deadline remains required for pathological streaming/tool behavior.

Readiness requires real JavaScript, native Capacitor Android platform and App.getState, actual visible Home identity/investigation links, no splash/dialog, and zero unexpected/native-blocked transport counters. Onboarding or unmet Home prerequisites block rather than being removed. Readiness alone returns READY_NOT_ACCEPTANCE. Only intentional lifecycle restart may create a fresh Page, never a hidden recovery for detached continuity.

Diagnostics retain fixed stage/category, boolean process/socket/target state, count of current targets, native action names, source/helper/APK/signer hashes and SDK versions. No raw logs, page content, target identifiers, tokens or arbitrary exception messages.
