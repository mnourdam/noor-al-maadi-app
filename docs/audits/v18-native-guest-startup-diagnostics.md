Only the owned probe process is killed on timeout/cap/error, never guest services or the emulator. Eleven probes therefore add a bounded post-failure diagnostic cost, up to 33 seconds including worst-case reaping, separate from the existing diagnostic queries. Capture reports complete/timeout/truncated/unavailable/cleanup_failed/reap_failed; failed or incomplete scalar probes are unavailable, not negative. Log indicators can describe a partial sample, and command_succeeded is true only on complete exit zero.

Raw data is transient inside the helper and never returned in the diagnostic report or written to files. Output contains fixed enum values, bounded uptime/byte count and boolean fatal/system-server/watchdog/SELinux/VM-init/dex text indicators. UTF-8 bytes are assembled before decoding, so chunk boundaries do not split matching. Indicator absence is not proof of healthy startup. No raw serial, PID, path, content, environment or exception message is retained.
