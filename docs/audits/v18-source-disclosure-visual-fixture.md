# Bounded source-disclosure visual fixture

Companion to static source disclosure commit ae56195. The sole app delta increases disclosure text from 11px/muted to 12px/foreground80, retaining leading6 and exact neutral wording. This is a readability intention, not measured accessibility compliance.

One new narrowly triggered workflow builds actual Sources, OriginalReferences, SourceDisclosure, parser and production CSS, using exact snapshot-pinned Duraid/dinar record slices. No full route or application shell, auth, API, service worker, content mutation, or data model activation. Vite uses no project config/public directory/environment directory; ambient VITE variables are scrubbed. Actual emitted JS module inclusion is checked. CSS fonts are emitted from locked local fontsource dependencies, not remotely copied; each emitted font/static asset is individually hashed in a private inventory. No directory-wide network fallback.

The guarded driver serves only exact inventory GET paths on ephemeral 127.0.0.1, rejects other origin/query/percent-encoding paths/redirects/WebSockets and blocks service workers. At 390x844 and1280x900 it checks all six entries verbatim, exact disclosure, loaded local fonts, no horizontal overflow and at least12px text, then saves four bounded PNGs and hashes. Actual images are for independent review, not automatic user delivery or proof of full-page layout. Receipt is sanitized and source-hash bound. Screenshots contain only already packaged public content, no credentials or personal data. Browser tooling is pinned Playwright1.62.0/its installed Chromium; version recorded, no local Chromium launch.

Navigation/bootstrap operations, font readiness, screenshots, build and total observation have finite deadlines. Context and server teardown are attempted on failure, with fixed categories and no raw logs. Browser profile and built files are temporary. Artifact retention is seven days. Workflow triggers only its five test/workflow files or explicit manual dispatch on the exact preparation branch. Later changes to those files can trigger another run; the single-run constraint is coordinator practice, not claimed one-shot enforcement. Existing workflow filters must be checked by coordinator before publication.

Offline validation: Node guard tests, actual Vite build and source graph/inventory checks only. No runtime/browser evidence exists until the one authorized remote run is reviewed.

Static receipts: 4/4 offline guard tests, 5/5 actual public route tests, both TypeScript no-emit configurations and diffcheck PASS. Actual local Vite build passed emitted-module verification and produced 63 individually hashed assets, including60 local font files; no browser was launched. PASS receipt now retains the full asset inventory and its sorted compact JSON SHA256, alongside source/record hashes, so fonts/CSS are not merely unrecorded build state. Actual screenshot/viewport review is still pending the one coordinated remote run.
