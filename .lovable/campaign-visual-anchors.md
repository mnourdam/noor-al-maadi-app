# Irth — Campaign Visual DNA Ledger

**Status:** Phase 2 audit complete — 71 published campaigns. **Awaiting approval before any artwork is generated.**

**Rule (permanent, frozen):** Every campaign must receive a **Visual DNA** record — not just a Visual Anchor. The Visual Anchor (Signature Landmark + Signature Object + Emotional Tone + figure policy + forbidden list) is a **subset** of the Visual DNA. No artwork of any kind — Hero Key Art, Story cover, promotional artwork, future expansions — may be generated for a campaign until its Visual DNA row is filled and approved. Once approved, the Visual DNA is **frozen** and reused consistently across the entire Irth ecosystem so the campaign carries one permanent visual identity everywhere it appears.

## Visual DNA schema

**Layer 1 — Visual DNA (frozen identity, 8 fields):** `primary_color_palette`, `lighting_style`, `weather_atmosphere`, `signature_landmark`, `signature_object`, `emotional_tone`, `camera_language`, `forbidden_elements`.

**Layer 2 — Anchor context (production guardrails):** `id`, `title_ar`, `era` / `world`, `years`, `figure_policy`, `reference_notes`.

**Figure policies:** `none` (no figures — place carries the story), `silhouette-only` (backs turned, shadow, night silhouettes), `crowd-distance` (many figures at scale where individuals cannot be identified), `named-later-figures-ok` (named figures from the 3rd Hijri century onward may be depicted at respectful distance and never Prophets/Companions).

**Universal Style Guide v1 rules that apply to every row below (do not repeat per campaign):** painterly realism; warm gold + deep navy tonal discipline; one dominant motivated warm light source; no baked-in text/logos/watermarks; no invented Arabic calligraphy; no modern skyline/paving/lighting/vehicles unless the campaign is 20th-century; negative space top-left / top-right for UI overlay; must read at 128px thumbnail; must feel like the same studio hand as the approved Emblems v1.

## Data-quality notes surfaced by the audit

- **`admin_campaigns.data->>'world'` is `null` on every published campaign.** World membership is currently derived only from the `era` tag via `ERA_TO_WORLD` in `src/lib/atlas/atlas-visual.ts`. - **`battle-of-zallaqa` has `era: "andalusia"` instead of `era: "andalus"`.** Every other Andalus campaign uses `andalus`. Recommend a one-line canonicalisation to `andalus` — non-blocking for artwork, but should be fixed before we build era-scoped surfaces around the campaign.
- **`battle-of-ain-jalut` uses `era: "mamluk"`; every other Mamluk campaign uses `era: "mamluk-sultanate"`.** Same recommendation — canonicalise to `mamluk-sultanate` at some future content sweep.
- **Divider entries (`div_*` ids)** in `admin_campaigns` are section headers, not real campaigns; they are excluded from this audit and should never receive Visual DNA or artwork.
