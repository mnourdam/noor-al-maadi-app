Every campaign must receive a **Visual DNA** record (not just a Visual Anchor) before any artwork of any kind is generated for it — Hero Key Art, Story cover, promotional artwork, future expansions all draw from the same DNA.

Visual DNA has 8 frozen fields (Layer 1):
1. Primary Color Palette
2. Lighting Style
3. Weather / Atmosphere
4. Signature Landmark
5. Signature Object
6. Emotional Tone
7. Camera Language
8. Forbidden Elements

The Visual Anchor is a subset of the Visual DNA. Once approved the DNA is FROZEN — no silent changes to the 8 fields; revisions require an explicit re-approval turn and must propagate everywhere the campaign appears.

**Why:** guarantees one permanent visual identity for each campaign across the entire Irth ecosystem.

**How to apply:** ledger and schema live at `.lovable/campaign-visual-anchors.md`. During Phase 2 audit, every published campaign gets both a Visual Anchor and a complete Visual DNA row. No artwork generation begins until the full audit is finished and approved.
